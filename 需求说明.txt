用TS创建一个网页文本编辑器
此文本编辑器打开一个本地文件夹后可以使用
这个文件夹存放图片,文本文件,子文件夹,和一个json文件记录文本文件和图片的位置(Element_position.json);
这个编辑器的新项目页面是一个带坐标系的网格画布
使用上下左右键可以切换网格
此文本编辑器有一个坐标起始点(0.0)
x轴向右(不可见)
y轴向下(不可见)
此编辑器由可以存放字母的网格组成
一个网格长度宽度为1单位
每个格的长宽比例为1:1
所有文本存放在文本文件中
创建文本文件在空白网格出输入xxx.txt可创建一个1x1的网格,此文本文件内容为一个空格
文本文件在网格画布中的样式:
从文件名向下向右
创建一个文本矩形区域用于存放文本
这个矩形区域紧紧包裹文本,向右到最长的一行,向下到最后一行;
在文本矩形使用上下左右移动时,从文本矩形的左右边无法移出此文本矩形,从上下可以移出;
每个格只存放一个字符
存放空格用透明点表示ㆍ
存放换行符用透明向下向左箭头表示↵

npm install
npm run dev
